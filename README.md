# LegoTech 📚

**LegoTech** is a ecommerce demo platform designed to showcase product browsing, cart features, and full admin management.

---

## 🚀 Dependencies

* Docker
* Docker Compose
* PHP 8.4
* Laravel

---

## ⚡ Quick Start

### 1️⃣ Clone Repository

```bash
[git clone https://github.com/emanuel-o-dev/legotech.git
cd legotech
```

### 2️⃣ Define Environment Variables

```bash
cp .env.example .env
```

### 3️⃣ Install Dependencies

```bash
./run composer install
```

### 4️⃣ Up the Containers

```bash
./run up -d
```

### 6️⃣ Create Database and Tables

```bash
./run db:reset
```

---

## 🧪 Run Tests

* **PHPUnit**

```bash
./run test
```

* **PHPCS (Code Sniffer)**

```bash
./run phpcs
```

* **Laravel Dusk**

```bash
./run dusk
```

* **PHPStan**

```bash
./run phpstan
```
